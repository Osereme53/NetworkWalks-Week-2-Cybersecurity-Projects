Week 2 – Cybersecurity Internship Projects

Overview

This repository contains my Week 2 practical assignments completed as part of the NetworkWalks Cybersecurity Internship Programme.

The projects focus on passive reconnaissance, network scanning, and technical reporting. They demonstrate practical experience using cybersecurity tools in a controlled learning environment.

Projects Completed

1. W2-PM4: theHarvester-Based Footprinting Attacks

Tools: Kali Linux, theHarvester 4.10.1, crt.sh

Objective: To gather publicly available information about a target domain and understand its digital footprint through passive OSINT techniques.

Activities:

* Verified theHarvester installation and functionality.
* Conducted passive footprinting against tesla.com.
* Used Certificate Transparency records through crt.sh.
* Discovered 236 hostname entries.
* Exported results in JSON and XML formats.
* Analysed the findings and documented the results.

Key Skills: Passive OSINT, domain footprinting, information gathering, and security analysis.

2. W2-PM5: Zenmap-Based Network Scanning

Tools: Kali Linux, Zenmap, Nmap

Objective: To perform network discovery and scanning using Zenmap’s graphical interface.

Activities:

* Identified network hosts in the lab environment.
* Used Zenmap to perform network scanning.
* Examined discovered hosts and scan results.
* Documented the scanning process and findings.

Key Skills: Network reconnaissance, host discovery, network scanning, and result interpretation.

3. W2-PM-FINAL: Detailed Module Report

Objective: To prepare a detailed report covering the selected modules and practical activities completed during Week 2.

Activities:

* Reviewed the selected learning modules.
* Documented the practical exercises and tools used.
* Summarised key findings and learning outcomes.
* Prepared a structured technical report.

Key Skills: Technical writing, cybersecurity documentation, research, and reporting.

Skills and Knowledge Gained

* Passive reconnaissance and OSINT.
* Network discovery and scanning.
* Domain footprinting.
* Certificate Transparency research.
* Cybersecurity tools and Linux environment.
* Technical documentation and reporting.
* Security analysis and interpretation of findings.

Evidence and Documentation

This repository contains the reports and practical evidence associated with the three Week 2 assignments, including screenshots showing tool verification, execution steps, and results.

Conclusion

The Week 2 projects provided practical exposure to reconnaissance, network scanning, and cybersecurity reporting. They strengthened my understanding of how security professionals gather information, identify network assets, analyse findings, and document security activities.
